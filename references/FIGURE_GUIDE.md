# FIGURE_GUIDE：图件提取、子图识别和交互

## 1. 核心原则

完整原图优先。**只有原图明确印有 `(a)`、`(b)`、`(c)` 等面板字母，或图注明确按这些字母分别描述时，才是独立子图。**

多个折线图、柱状图、热图、流程框、网络区域、颜色分区或局部结构，如果没有原文面板字母，仍然是一张完整图，不得人为拆分。

## 2. 提取完整原图

1. 从图注或正文定位图号和 PDF 页码。
2. 检查 PDF 页面，确定完整图件边界。
3. 高分辨率提取，保留图题、面板字母、坐标轴、单位、图例和注释。
4. 不要用缩放后的屏幕截图替代原图。
5. 检查图片四边，确认没有裁掉必要元素。
6. 记录图号和实际 PDF 页码。

命令示例：

```bash
python scripts/crop_pdf_figure.py paper.pdf 8 figures/fig4.png --dpi 260
```

可选 `--rect x0 y0 x1 y1` 指定 PDF 页面坐标（point，左上角为原点）。坐标必须来自实际 PDF 页面，不得猜测。

## 3. 子图判定

逐项检查：
- 原图中是否能看到 `(a)`、`(b)`、`(c)` 等字母？
- 图注是否按字母分别描述？
- 字母是否对应独立面板？
- 面板边界是否能准确确定？

无法确认就不创建子图热点。可以在整图说明中解释图内不同组成部分，但不得称其为独立子图。

## 4. 面板字段

每个面板填写：
- `letter`：原图面板字母；
- `rect`：完整原图中的归一化边界；
- `title`：该面板回答的问题；
- `purpose`：实验目的/对照设计；
- `how`：坐标轴、单位、图例、颜色、行列和统计标记；
- `result`：直接观察结果；
- `significance`：对全文论证的作用；
- `limit`：证据边界；
- `source`：图号和页码；
- `crop_image`：可选局部高清图。

## 5. 热点坐标

```text
x0 = 面板左边界像素 / 完整原图宽度
y0 = 面板上边界像素 / 完整原图高度
x1 = 面板右边界像素 / 完整原图宽度
y1 = 面板下边界像素 / 完整原图高度
```

坐标格式 `[x0,y0,x1,y1]`，范围 0–1。不得将裁剪图坐标直接用于完整原图热点。

标注工具：

```bash
python scripts/mark_panels.py figures/fig4.png figures/fig4_panels.html
```

打开页面拖框并输入原文面板字母，导出坐标，再补全解释字段。必须人工核对。

## 6. 交互方式

- 点击正文图件入口：打开完整原图。
- `panels` 为空：只显示完整原图，不出现热点。
- `panels` 有内容：仅在明确标注面板上显示热点。
- 点击热点：在原图旁显示局部放大图和解释卡片。
- 再次点击同一面板、关闭按钮或 Esc：关闭卡片。
- 移动端卡片排在原图下方。
- 术语卡片独立为小型浮动卡片，不覆盖整页。

## 7. 验收清单

- [ ] 完整原图、坐标轴、单位、图例和注释完整。
- [ ] 只有明确标注的面板才有热点。
- [ ] 热点与原图面板准确对应。
- [ ] 局部图对应正确面板且没有裁掉必要信息。
- [ ] 图解引用正确页码和图号。
- [ ] 没有面板字母的图保持完整图状态。
