# 组合图逐子图深度解读工作指南

## A. 逐图工作单（先做分析，再编码）

对一张带 a/b/c/... 的组图：

1. 确认作者图注中每个字母对应什么测量，检查图片位置与图注是否一致。
2. 标明样品、时间、处理、对照；对微观图说明染色颜色和放大/比例尺，对定量图说明坐标单位和重复数，对机制图说明箭头是“示意”还是因果实验证据。
3. 用一两句话报告面板本身的观察；必要时引用正文的原文数字，但不要从图上目测一个虚假的精确数。
4. 解释该面板在整篇论证链中的作用，与其他面板之间是并列证据、顺序步骤还是因果验证。
5. 写解读边界：是否只有体外、小鼠或特定细胞模型；相关是否可证明因果；“显著”是否有统计检验；有限例数能否支持一般化。
6. 给准确 `source`：Fig. [编号][子图字母]，PDF物理页码，必要时关联原文 Results 和 Supplementary Fig.。

## B. 常见子图读图重点

| 类型 | `how` 必须说明 |
|---|---|
| 示意流程 | 输入对象、箭头逻辑、时间、培养/算法条件、输出；它是不是实测结果？ |
| 显微/相差图 | 分组、对照、时间、放大/比例尺、细胞形态变化，不以视觉密度估算精确细胞数 |
| 免疫荧光多通道 | 每个颜色对应什么标志物，Hoechst/DAPI 核染，行列组合、合并图，阳性与表达强度的区别 |
| 生长曲线 | x/y 轴、组别、重复数与误差棒，是否真实计数或理论累计计算 |
| 柱状图组合 | 每小图指标、不同量纲、组别、误差棒、显著性来源，不混淆各纵轴 |
| Kaplan–Meier 生存 | 事件及观察时间、每组样本量、删失标识、是否有组间统计检验 |
| 流式/倍性图 | 染料、门控、2c/4c/8c 的意义、比例与绝对计数区别、细胞周期混杂可能 |
| 蛋白免疫印迹 | 总蛋白 vs 磷酸化蛋白，上样对照、时间点与药物处理，信号激活不等于直接靶基因调控 |
| 转录组热图 | 标准化单位、颜色高低、行列含义、样本/基因聚类和技术/生物重复区分 |
| 相关性热图 | 相关系数范围、对应样本分组、相似度不等于功能等同性 |
| 敲低/过表达 | 操纵是否生效、对照、表型、重复数和统计、是否能推出因果必要性或充分性 |

## C. 可点击交互严格约束

- 打开图像后只有原图；不自动显示文字解释。
- 子图用独立热点覆盖，默认透明，只显示小小的字母标签；hover 可以高亮热点，但**解释卡片只能 click 打开**。
- 若一张图存在 8 个子图，应有 8 个独立热点与 8 条有依据的解释。不得把整个组图当作一个热点。
- 用户点击 b 时替换 a 的卡片；再次点击 b 收起；点击卡片 X、Esc 也关闭。
- 展开后右侧/下方显示该子图局部放大，并有 5 个条目：实验目的、怎么看、观察结果、论证作用、解读边界。卡片顶部给准确图号。
- 手机端以原图在上、解释在下呈现；图片与热点共享同一比例坐标，缩放不应错位。
- 不把空的详情链接/按钮渲染出来；所有文字处理用 textContent 或 HTML 转义，避免非可信论文文本被当成 JS 代码执行。

## D. 从像素坐标换算成比例

如果图像实际宽 `W`、高 `H`，人工圈出面板左上右下为 `(x0px, y0px, x1px, y1px)`：

```
rect = [x0px/W, y0px/H, x1px/W, y1px/H]
```

例如图宽 1000 px，高 800 px，面板是 `[100, 80, 420, 360]`，则 JSON 为 `[0.1, 0.1, 0.42, 0.45]`。这个例子不属于具体论文，不能复制到真实面板。对 PDF 中独立提取的图像重新裁切时，必须重新标注。

可以使用：

```
python scripts/mark_panels.py figures/figure1.png figures/figure1_selector.html
```

拖拽框选并给字母命名后导出坐标 JSON，再填充每个面板的文字字段。标注工具仅提供坐标，它不负责学术解释；学术解释必须从论文原文得到。

## E. 正式发布前核查

- 对照原始页面核对原图字母 a—n、分组和图例。
- 在 `--debug-hotspots` 模式下逐个点击，并核查放大裁剪是否含关键坐标或相关染色组。
- 将每个 `result` 与 PDF 原文重新逐项比对；明确是否作者推断或分析者解释。
- 确认不将来源证据误说成因果验证，例如存活提升可能同时受到模型选择压力等影响。
- HTML 不出现外链资源，不会悬停自动显示解释，宽/窄屏可操作。
