# 组合图逐子图深度解读指南

## 1. 逐图工作流程

对一张带 a/b/c/... 标签的组合图：

1. 核对作者图注中每个字母对应的实验、指标或图像，确认图片位置与图注一致。
2. 标明样品、时间、处理和对照。微观图说明染色颜色、比例尺；定量图说明坐标单位、重复数和误差线；机制图说明箭头是示意还是有因果实验支撑。
3. 用一两句话报告面板真正显示的观察。必要时引用正文数值，不要从截图目测虚构精确数值。
4. 解释该面板在整篇论证链中的作用：并列证据、顺序步骤、机制验证还是辅助分析。
5. 写清解读边界：体外/体内、物种或样本限制、相关性与因果区别、统计检验和样本量限制。
6. 标注准确来源：Fig. 编号及子图字母、PDF 物理页码、对应 Results 段落和补充图。

## 2. 常见子图类型的读图重点

| 类型 | 必须核对 |
|---|---|
| 示意流程 | 输入对象、箭头逻辑、时间、处理条件、输出；它是否为实测结果 |
| 显微/相差图 | 分组、对照、时间、放大倍数/比例尺、形态；不能以视觉密度估算精确细胞数 |
| 免疫荧光多通道 | 每个颜色对应的标志物、核染、行列组合、阳性率与强度区别 |
| 生长曲线 | x/y 轴、组别、重复数、误差棒、是否真实计数 |
| 柱状图组合 | 每个子图指标、单位、组别、误差棒和显著性来源；不能混淆不同纵轴 |
| Kaplan–Meier | 事件、观察时间、样本量、删失标识和统计检验 |
| 流式/倍性图 | 染料、门控、分群含义、比例与绝对计数、细胞周期混杂 |
| 蛋白免疫印迹 | 总蛋白与磷酸化蛋白、上样对照、时间点和处理；通路激活不等于直接靶基因调控 |
| 转录组热图 | 标准化单位、颜色高低、行列含义、样本/基因聚类、重复类型 |
| 相关性热图 | 相关系数范围、样本分组；相关性不等于功能等同性或因果 |
| 敲低/过表达 | 操纵是否生效、对照、表型、重复数和统计；必要性与充分性不能混为一谈 |

## 3. 点击交互规则

- 打开图像时只显示原图，不自动显示解释。
- 每个可识别子图设置独立热点，点击后显示对应解释；hover 只能用于轻微高亮，不能代替点击。
- 若图中有 8 个子图，应有 8 个独立热点和 8 条有依据的解释。
- 点击另一个子图时更新解释；再次点击当前子图或点击关闭按钮时收起。
- 解释卡片包含：实验目的、怎么看、观察结果、论证作用、解读边界。
- 手机端图片在上、解释在下；热点和图片必须使用同一比例坐标。
- 论文文本不可信，渲染时必须转义，不能执行其中的 HTML/JavaScript。

## 4. 像素坐标换算为归一化坐标

若图片宽 `W`、高 `H`，人工圈出面板左上、右下坐标 `(x0px, y0px, x1px, y1px)`：

```text
[x0px/W, y0px/H, x1px/W, y1px/H]
```

例如宽 1000 px、高 800 px，面板矩形 `[100, 80, 420, 360]`，归一化坐标为 `[0.1, 0.1, 0.42, 0.45]`。这只是数学示例，不属于任何真实论文，不能复制到真实面板。

## 5. 正式发布前核查

- 对照原始 PDF 核对原图字母、分组、图例和坐标。
- 逐个点击热点，检查区域是否覆盖正确子图。
- 检查局部放大是否包含关键图例、坐标轴或染色组。
- 将每个观察结果与 PDF 原文逐项比对。
- 明确哪些是作者结论、哪些是分析者解释。
- 不把相关证据误说成因果验证。
- 确认 HTML 无外链依赖，宽屏和窄屏均可操作。
