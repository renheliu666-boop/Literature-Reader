# 组合图逐子图深度解读工作指南

## A. 逐图工作单（先做分析，再编码）

对一张带 a/b/c/... 的组图：

1. 确认作者图注中每个字母对应什么测量，检查图片位置与图注是否一致。
2. 标明样品、时间、处理和对照；微观图说明染色颜色和比例尺，定量图说明坐标单位和重复数，机制图说明箭头是示意还是因果实验证据。
3. 用一两句话报告面板本身的观察；必要时引用正文数字，不要从图上目测虚假的精确值。
4. 解释该面板在整篇论证链中的作用，与其他面板之间是并列证据、顺序步骤还是因果验证。
5. 写明解读边界：是否只有体外、小鼠或特定细胞模型；相关是否能证明因果；显著性是否有统计检验；有限例数能否支持一般化。
6. 给准确 `source`：Fig. [编号][子图字母]、PDF物理页码，必要时关联 Results 和 Supplementary Fig.。

## B. 常见子图读图重点

| 类型 | `how` 必须说明 |
|---|---|
| 示意流程 | 输入对象、箭头逻辑、时间、培养/算法条件、输出；它是不是实测结果？ |
| 显微/相差图 | 分组、对照、时间、放大/比例尺、细胞形态变化；不以视觉密度估算精确细胞数 |
| 免疫荧光多通道 | 每个颜色对应什么标志物、核染、行列组合、合并图、阳性与表达强度区别 |
| 生长曲线 | x/y 轴、组别、重复数与误差棒，是否真实计数或理论累计计算 |
| 柱状图组合 | 每个小图的指标、量纲、组别、误差棒和显著性来源，不混淆纵轴 |
| Kaplan–Meier 生存 | 事件及观察时间、每组样本量、删失标识、组间统计检验 |
| 流式/倍性图 | 染料、门控、2c/4c/8c 意义、比例与绝对计数区别、细胞周期混杂 |
| 蛋白免疫印迹 | 总蛋白与磷酸化蛋白、上样对照、时间点和药物处理；信号激活不等于直接靶基因调控 |
| 转录组热图 | 标准化单位、颜色高低、行列含义、样本/基因聚类、技术/生物重复 |
| 相关性热图 | 相关系数范围、样本分组；相似度不等于功能等同性 |
| 敲低/过表达 | 操纵是否生效、对照、表型、重复数和统计，能否推出因果必要性或充分性 |

## C. 可点击交互严格约束

- 打开图像后只有原图；不自动显示文字解释。
- 子图用独立热点覆盖，默认透明，只显示小字母标签；hover 可以高亮热点，但解释卡片只能 click 打开。
- 一张图有多少个子图，就应有多少个独立热点与解释。
- 用户点击 b 时替换 a 的卡片；再次点击 b 收起；点击卡片 X、Esc 也关闭。
- 展开后显示实验目的、怎么看、观察结果、论证作用、解读边界，并提供局部放大。
- 手机端以原图在上、解释在下呈现；图片与热点共享同一比例坐标。
- 不把空的详情链接/按钮渲染出来；论文文本必须经过 HTML 转义或使用 `textContent`，避免非可信文本被当成代码执行。

## D. 像素坐标换算成比例

若图像宽 `W`、高 `H`，面板左上右下为 `(x0px,y0px,x1px,y1px)`：

```text
rect = [x0px/W, y0px/H, x1px/W, y1px/H]
```

例如图宽 1000 px、高 800 px，面板 `[100,80,420,360]`，JSON 为 `[0.1,0.1,0.42,0.45]`。这是格式示例，不属于具体论文，不能复制到真实面板。裁切图像后必须重新标注。

使用：

```bash
python scripts/mark_panels.py figures/figure1.png figures/figure1_selector.html
```

标注工具只提供坐标，不负责学术解释；学术解释必须从论文原文得到。

## E. 正式发布前核查

- 对照原始页面核对原图字母、分组和图例。
- 在 `--debug-hotspots` 模式下逐个点击，核查放大裁剪是否含关键坐标或相关染色组。
- 将每个 `result` 与 PDF 原文重新逐项比对，明确是否作者推断或分析者解释。
- 不将来源证据误说成因果验证。
- HTML 不出现外链资源，不会 hover 自动显示解释，宽/窄屏均可操作。
